# Agyflow — Directory & Launch Platform Submissions

Sumber inspirasi: thread @samsulhuda_ (84 direktori DR tinggi; thread asli login-wall,
hanya tweet pembuka yang terbaca) + database zplatform.ai/saas-directories (348 direktori,
DR terverifikasi Agustus 2026). Daftar di bawah sudah disaring: gratis dulu, DR tinggi,
relevan untuk produk Agyflow.

## Strategi
- Listing yang disubmit: **bundle Agency Compliance Toolkit** (agyflow.com + Gumroad link)
  dan **PrivacyPage AI** untuk direktori kategori AI.
- 1 produk = 1 listing. Jangan spam nama berbeda — akun kena ban.
- Field standar siapkan sekali, pakai berulang:
  - Name: Agyflow — Agency Compliance Toolkit
  - Tagline (60-80 char): "GDPR compliance toolkit for web agencies — checklists, audits, templates"
  - Short desc (150 char), Long desc (500 char): ambil dari upload-kits/gumroad-upload-kit.txt
  - Logo: 512x512, Screenshot: 1280x800 (2-3 buah: checklist, spreadsheet dashboard, landing page)
  - Link: https://agyflow.com (+ Gumroad product URL setelah live)
  - Pricing: Freemium / dari $9
- Urutan kerja: Tier A habis dulu (semua gratis), baru pertimbangkan yang berbayar.

## Tier C — nofollow tapi traffic/audience (tetap worth it)
- Reddit (DR 95): r/SideProject, r/EntrepreneurRideAlong, r/webdev — aturan stealth-ai:
  value dulu, link kemudian, jangan link di reply pertama.
- Hacker News (DR 91): Show HN untuk bundle — judul faktual, tanpa marketing hype.
- Medium / Dev.to / HackerNoon: tulis 1 artikel "GDPR compliance checklist for web agencies"
  + link toolkit. Sekalian SEO.
