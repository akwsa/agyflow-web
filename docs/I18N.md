# Agyflow i18n — English / German / French

Status: LIVE at agyflow.com (deployed 2026-09-09)
Repo: https://github.com/akwsa/agyflow-web

## URL Structure

| Language | URL       | Canonical | og:locale |
|----------|-----------|-----------|-----------|
| English  | `/`       | `/`       | en_US     |
| German   | `/de`     | `/de`     | de_DE     |
| French   | `/fr`     | `/fr`     | fr_FR     |

- English stays at root `/` (already indexed by Google — do not move it to `/en`).
- `x-default` hreflang points to `/`.
- Every page emits hreflang links for en / de / fr / x-default + own canonical.

## Architecture

Because `next.config.mjs` uses `output: "export"` (static export), Next.js
built-in i18n routing is NOT available. Instead:

- `lib/i18n.ts` — single source of truth. Three full dictionaries (`en`, `de`,
  `fr`) with a shared TypeScript type (`Dict`). German/French dict objects are
  type-checked against the English shape, so a missing key = build error.
- `app/page.tsx`, `app/de/page.tsx`, `app/fr/page.tsx` — one page per language.
  Each exports its own `metadata` (title, description, keywords, canonical,
  hreflang alternates, OpenGraph locale) and renders all sections with
  `<Component lang="xx" />`.
- All UI components (`Navbar`, `Hero`, `InteractiveAgentFlow`, `BentoGrid`,
  `ProductSuite`, `PricingSection`, `FaqSection`, `Footer`) accept a `lang`
  prop (default `"en"`) and read text from the dictionary. No hardcoded copy.
- `components/JsonLd.tsx` — emits Organization + SoftwareApplication + FAQPage
  schema, translated per language (FAQ questions/answers come from the dict).
- `app/sitemap.ts` — includes `/de` and `/fr` with `alternates.languages`
  (renders as `xhtml:link` entries in sitemap.xml).
- `scripts/fix-html-lang.mjs` — static export renders `<html lang="en">` for
  every page (single root layout). This post-build script rewrites
  `out/de.html` → `lang="de"` and `out/fr.html` → `lang="fr"`. Wired into
  `npm run build` (`next build && node scripts/fix-html-lang.mjs`). It fails
  the build if the localized pages are missing.
- `public/.htaccess` — production Apache config for Rumahweb hosting:
  HTTPS redirect + security headers + caching (pre-existing) plus:
  `RewriteRule ^de/?$ de.html` and `RewriteRule ^fr/?$ fr.html`.
  With `trailingSlash: false`, the build emits `de.html` / `fr.html`, so these
  rewrites make `/de` and `/fr` resolvable. The generic fallback
  (`/index.html`) stays last.

## How to Add a New Language (e.g. `es`)

1. `lib/i18n.ts`: add `export type Lang = ... | "es"`, add `"es"` to `LANGS`,
   add a `const es: Dict = {...}` translation and register it in
   `dictionaries` + `LANG_META` (`htmlLang`, `ogLocale`).
2. Copy `app/fr/page.tsx` → `app/es/page.tsx`, change `"fr"` → `"es"`
   (including canonical `/es` and hreflang entry `es: "/es"`).
3. `app/page.tsx`, `app/de/page.tsx`, `app/fr/page.tsx`: add `es: "/es"` to
   each page's `alternates.languages`.
4. `app/sitemap.ts`: add `/es` entry + include in `languages` map.
5. `components/Navbar.tsx`: add `es: "/es"` to `LANG_HREF`.
6. `scripts/fix-html-lang.mjs`: add `{ file: "out/es.html", lang: "es" }`.
7. `public/.htaccess`: add `RewriteRule ^es/?$ es.html [L]`.
8. Build, verify (`grep '<html lang="es"' out/es.html`), upload.

## Build & Deploy (Rumahweb cPanel)

```bash
npm run build          # emits out/ and fixes <html lang> on de.html/fr.html
```

Upload ALL of `out/` into `public_html/` via cPanel File Manager or FTP
(hosting credentials are in `agyflow-main.md` — never commit that file).
The `out/.htaccess` must be uploaded too (hidden file — enable "show hidden
files" in File Manager). Server is LiteSpeed/Apache; PHP is present but unused
(static site).

## Post-Deploy Verification Checklist

```bash
curl -s https://agyflow.com/    | grep -o '<html lang="[a-z]*"'          # en
curl -s https://agyflow.com/de  | grep -o '<html lang="[a-z]*"'          # de
curl -s https://agyflow.com/de  | grep -c 'hrefLang'                     # >= 4
curl -s https://agyflow.com/fr  | grep -o '<title>[^<]*</title>'         # FR title
curl -s https://agyflow.com/sitemap.xml | grep -c 'agyflow.com/\(de\|fr\)'  # 8
```

## Known Limitations

- Old hashed chunks remain in `_next/` on the server (harmless; clean by
  deleting `_next/` before re-upload if desired).
- Pricing/credits are identical across languages (USD, Lemon Squeezy MoR).
- `manifest.json`, favicon, hero image are language-neutral.
