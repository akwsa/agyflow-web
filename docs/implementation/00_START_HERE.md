## 🚀 **5-Step Quick Start**

### **Total Time: 5 minutes setup → 16 days automated build**

### **Step 1: Copy Gemini Key from Existing Project (30 seconds)** ⚡

```bash
# Get existing Gemini key from AGY projects:

# Option 1: From GDPR Privacy Policy Assistant
cat m:\saas\saas\gdpr-privacy-policy-assistant\.env | grep GEMINI_API_KEY

# Option 2: From AI Customer Support Assistant  
cat m:\saas\saas\ai-customer-support-reply-assistant\.env | grep GEMINI_API_KEY

# Copy the key value (AIza...)

# ✅ Other keys already configured in newapikey.txt:
# - Agnes AI ✅
# - Atria ASI ✅
# - CommandCode ✅
# - OpenRouter ✅
```

### **Step 2: Install Tools (2 min)**

```bash
# Install 9router CLI
npm install -g @9router/cli

# Install project dependencies
cd m:\saas\saas\agyflow-web
npm install @9router/core @9router/hermes-adapter
```

### **Step 3: Configure (1 min)**

```bash
# Copy pre-configured environment
cp .env.9router.example .env.9router

# Add your Gemini key from Step 1
nano .env.9router
# Update: GOOGLE_AI_API_KEY=AIza... (from existing project)

# All other keys are already there! ✅
# - AGNES_API_KEY ✅
# - ATRIA_ASI_API_KEY ✅
# - COMMANDCODE_API_KEY ✅
# - OPENROUTER_API_KEY ✅
```

### **Step 4: Validate (2 min)**

```bash
# Test configuration
9router validate

# Test models
9router test-models

# Expected: All green checkmarks ✅
```

### **Step 5: Build! (16 days automated)**

```bash
# Start Hermes coordinator
npm run hermes:start

# Run 9router (dry-run first)
9router run --dry-run

# Actual build
9router run --config 9router.config.yaml

# Monitor
9router status
```

**Done! Build runs automatically for 16 days.** 🎉

### **Common Issues:**

**"9router command not found"**
```bash
npm install -g @9router/cli
# or use npx
npx @9router/cli validate
```

**"Google AI key invalid"**
- Check format: AIza... (not sk-...)
- Verify API is enabled: https://console.cloud.google.com/apis/

**"Agent failed"**
```bash
# Check logs
9router logs --agent=auth_agent

# Retry specific agent
9router retry --agent=auth_agent
```
